# Product Requirements Framework

Rules for the product side of a requirements repo — charter, initiatives, epics, milestones, product requirements,
decisions, and mockups — each carrying a stable, citable `preq:<slug>` id.

Read [`./context/index.md`](./context/index.md) when working in or changing a product-focused requirements repo, or to
resolve a cited `preq:` id to the file that owns it.
